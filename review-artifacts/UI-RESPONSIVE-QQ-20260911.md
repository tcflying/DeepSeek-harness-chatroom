## 故障归因与实现

| 问题 | 当前证据与修复 |
| --- | --- |
| 手机聊天被侧栏挤窄 | 390 CSS px 下原生展开侧栏仍占 280px，聊天区约 110px，头部高约 417px。插件改为 56px 原生收起栏 + 覆盖式抽屉；显式指定中间区和详情区网格列，避免固定定位后自动放置错列。 |
| 头部控件堆叠 | 原生按钮容器不收缩。改为语义槽位网格分行，Agent 列表由 details 按需展开，保留原生刷新/子 Agent 行为。 |
| 字号和品牌 | 初始/无效存储默认 QQ2007，明确保存的原生偏好仍保留。QQ 正文与输入至少 16px，较大的宿主内容字号保留；语义品牌槽位使用已有经典企鹅素材及 QQ2007 字标，退出 QQ 风格恢复原品牌。 |
| 抽屉遮罩误点 | 第一轮实测遮罩几何中心落在侧栏下面，点击触及底下列表。现限定可点击区域为抽屉右侧，原生 toggleSidebar 关闭；实测标题保持 Hello World。 |
| AI 成员表单溢出 | 390px 面板 scrollWidth 490px；原双列表单被模型选项最小宽度撑开。手机单列、输入约束宽度，最终 scrollWidth/clientWidth 均 390。 |
| 设置页内容过窄 | 原生通用设置左侧导航 188px，内容仅约 186px。窄屏全部设置章节使用顶部横向导航，内容约 373px；群聊与账号章节同样验证。 |
| 输入工具栏占高 | 发送按钮另起一行，390px 输入卡片约 199px。尾部控件用受约束网格，最终约 160px，模型名可截断但保留完整可访问标签，发送按钮仍可见。 |
| 表情菜单越界 | 菜单右边约 434px，超出 390px 视口；通用 QQ dialog 高度覆盖菜单滚动高度。窄屏固定在可视范围并恢复 280px/42dvh 上限；实测左右 64/382px，高 280px，可滚动。 |
| 详情栏折叠错列 | 侧栏固定定位后，原生详情列自动排到空出的第 1 列，折叠时仍宽 56px。显式 grid-column:3；最终原域名实测折叠宽度 0。打开状态 CSS 回归宽度为 viewport - 56px。 |

未把重载或 HTTP 200 当成以上根因证据；依据实际 DOM 结构、计算样式、几何和点击结果修复。所有宿主选择器使用语义槽位/结构，没有写入宿主哈希类名。
