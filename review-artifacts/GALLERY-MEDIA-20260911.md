## Fault attribution and recovery boundaries

1. Prior production proxy SSE leakage was already isolated/repaired in rc1.20 (`BRIDGE-LEAK-20260911.json`, old 20 remaining vs fixed 0). This release preserves that fix; it does not relabel every network error as the same cause.
2. This turn an older original page remained at “connection timeout” after deployment activity and recovered when the real reconnect button was used. The code lacked recovery for **EventSource.CLOSED**: `onerror` only changed a label. Browser automatic retry applies to CONNECTING, not permanently CLOSED streams (e.g. rejected HTTP/MIME). rc1.22 revalidates login and recreates only the read streams with one shared 1.5–30s backoff, cancelled on hidden/stop. A deterministic regression covers CLOSED, deduplication, GET-only recovery and hidden cancellation. The precise HTTP response that closed the historical original browser stream was not captured; it remains an inference, not a proven initiating trigger.
3. `TRANSPORT-PROBE-1789123234609.json`: four actual loopback/public WebSocket probes, including 7.5s delayed pong, remained connected through 45 seconds and were closed by the probe. This is bounded current evidence, not permanent WAN reliability.
4. `GALLERY-MEDIA-tls-20260911.json`: default Node fetch direct-to-Cloudflare repeatedly returned `ECONNRESET`; curl used the machine's existing proxy (`remote_ip=127.0.0.1`) and returned 200 for the same valid health/module targets. Running the verifier with Node's supported `--use-env-proxy` returned public 200 and matching origin bytes. Only the diagnostic process was changed; no global proxy, TLS, tunnel or protection setting was changed. Early static-module probes also lacked the required boot-manifest revision and correctly returned 404; those were probe errors, not missing plugin delivery.
5. Historical 13:34 initiating process/network trigger remains unknown: contemporaneous capture is absent. Current sanitized journals are enabled, healthy, dropped=0 and now record video submit/success/failure in addition to image, provider and native connection events. Previously paused recurring automation was not silently resumed.
